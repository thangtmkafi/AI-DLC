KAFI · AI-DLC v1.0 INSTALLER GUIDE

Installing v1.0 is a conversation, not a script.

This page is the stable entry point. It summarizes what installing and running AI-DLC v1.0 involves and sends you to the versioned guide, which is normative.

Cài v1.0 là một cuộc hội thoại, không phải chạy script.

Trang này là lối vào ổn định. Nó tóm tắt việc cài đặt và vận hành AI-DLC v1.0 rồi dẫn bạn tới guide có version — tài liệu normative.

Release status. The currently published release is v0.9.1. v1.0 is in preparation and is not published yet. Nothing on this page offers a v1.0 download; it describes how installation will work and how it is governed.
Trạng thái release. Bản đang phát hành là v0.9.1. v1.0 đang chuẩn bị và chưa phát hành. Trang này không cung cấp bản tải v1.0; nó mô tả cách cài đặt sẽ diễn ra và được quản trị ra sao.

01 · WHAT YOU INSTALL

One universal release, three agents.

There is no edition to choose and no per-host download. The same release serves Codex, Claude Code, and Kiro, and the same committed project state is readable by all three.

Một bản universal, ba agent.

Không phải chọn edition, không có bản tải riêng theo host. Cùng một release phục vụ Codex, Claude Code và Kiro, và cùng một project state đã commit đọc được ở cả ba.

02 · HOW IT INSTALLS

One prompt, then one approval.

You paste the prompt below into your agent. It discovers the release, inspects your project, and returns an exact plan with its digest. Nothing is created, moved, backed up, or deleted until you approve that exact digest.

Một prompt, rồi một lần phê duyệt.

Bạn dán prompt bên dưới vào agent. Nó khám phá release, kiểm tra dự án, và trả về plan chính xác kèm digest. Không file nào được tạo, di chuyển, backup hay xoá cho tới khi bạn duyệt đúng digest đó.

Use the KAFI AI-DLC Bootstrap Locator at
https://raw.githubusercontent.com/thangtmkafi/AI-DLC/main/.well-known/kafi-aidlc-bootstrap.json.
Inspect this project and the immutable public release, then present the exact
installation or upgrade plan and its digest. Do not create, update, merge,
move, delete, back up, or migrate any project file until I approve that digest.
Preserve the project root README.md.
One trust anchor. https://raw.githubusercontent.com/thangtmkafi/AI-DLC/main/.well-known/kafi-aidlc-bootstrap.json is the only locator. If a page, a message, or an agent offers you a different one, stop.
Một trust anchor duy nhất. https://raw.githubusercontent.com/thangtmkafi/AI-DLC/main/.well-known/kafi-aidlc-bootstrap.json là locator duy nhất. Nếu một trang, một tin nhắn hay một agent đưa bạn địa chỉ khác, hãy dừng lại.
NO ELEVATION

No administrator rights, no new runtime

On Windows the agent stages through PowerShell 5.1 without changing execution policy, and runs no .ps1, .bat, .cmd, or .exe.

Không cần quyền admin, không cần cài thêm runtime

Trên Windows agent staging qua PowerShell 5.1 mà không đổi execution policy, và không chạy .ps1, .bat, .cmd hay .exe.

IMMUTABLE

The bytes cannot change under you

The release is immutable: published assets cannot be replaced afterwards, so the plan digest you approved keeps meaning the same bytes.

Bytes không thể đổi sau lưng bạn

Bản release là immutable: asset đã publish không thể bị thay thế, nên plan digest bạn duyệt vẫn trỏ đúng bytes đó.

YOUR README

Your root README.md is never taken

AI-DLC packages never claim a consuming project's root README. That file belongs to your project, in v1 and in every version before it.

README.md gốc của bạn không bao giờ bị chiếm

Package AI-DLC không bao giờ chiếm README gốc của dự án. File đó thuộc về dự án của bạn, ở v1 và ở mọi version trước đó.

UPGRADE

Direct from v0.3-v0.9.x

No staged hops and no automatic relocation of your content. Anything the plan would move is listed in the plan; you approve it or you do not.

Trực tiếp từ v0.3-v0.9.x

Không phải nâng cấp qua nhiều chặng và không tự động di chuyển nội dung của bạn. Mọi thứ plan định di chuyển đều được liệt kê trong plan; bạn duyệt hoặc không.

04 · LEGACY v0.x

Legacy v0.x — the v0 installer.

The v0 line installs by script, selects an edition, and relocates existing files. It is documented for teams still running it, and it is not the v1.0 path.

Legacy v0.x — installer của v0.

Dòng v0 cài bằng script, chọn edition, và di chuyển file có sẵn. Ghi lại cho các team còn chạy nó, và đây không phải đường đi của v1.0.

curl -fsSL https://raw.githubusercontent.com/thangtmkafi/AI-DLC/main/tools/install.sh | bash
iwr -useb https://raw.githubusercontent.com/thangtmkafi/AI-DLC/main/tools/install.ps1 -OutFile install.ps1; .\install.ps1

It accepts --edition=claude-code|kiro, pins with --version=v0.9.1, and offers a --convert-to= mode. To reach v1.0 you do not need it: the v1 bootstrap prompt migrates v0.3-v0.9.x directly.

Nó nhận --edition=claude-code|kiro, ghim version bằng --version=v0.9.1, và có chế độ --convert-to=. Để lên v1.0 bạn không cần nó: prompt bootstrap của v1 migrate trực tiếp từ v0.3 đến v0.9.x.
