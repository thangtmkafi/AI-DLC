Git for non-developers

A visual, role-friendly handbook for PMs, BAs, Product Designers, and POs working inside AI-DLC. Covers Git fundamentals with diagrams, the KAFI stage = branch model, three tool tracks (Git Extensions on Windows, Fork on Mac, command line), troubleshooting, and a printable cheat sheet.

Sổ tay trực quan, viết cho PM, BA, Product Designer và PO tham gia AI-DLC. Khái niệm Git cơ bản kèm sơ đồ, mô hình stage = branch của KAFI, ba cách dùng (Git Extensions trên Windows, Fork trên Mac, dòng lệnh), xử lý sự cố, và bảng tra in được.
