How each role runs the system — and what changes per project profileCách mỗi role vận hành hệ thống — và điều gì thay đổi theo từng project profile

Every role uses the same four commands; the engine resolves what is applicable from the Project Profile (Entry × Scope × Relationship × Work type) and the operating model. So each guide below is written as a base flow — identical for every project — plus a delta table: what changes for you when the profile changes. You never manually skip a stage; capabilities that don't apply simply never reach you.Mọi role dùng chung bốn command; engine tự resolve những gì applicable từ Project Profile (Entry × Scope × Relationship × Work type) và operating model. Vì vậy mỗi hướng dẫn dưới đây gồm một base flow — giống hệt nhau cho mọi dự án — cộng một bảng delta: điều gì thay đổi cho bạn khi profile thay đổi. Bạn không bao giờ phải tự tay bỏ qua một stage; capability nào không áp dụng thì đơn giản là không bao giờ đến tay bạn.
