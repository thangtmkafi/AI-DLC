AI-DLC v1.0 documentation.

One universal release for Codex, Claude Code, and Kiro. Installed by prompt, governed by approved plan digests, shipped as an immutable release.

Tài liệu AI-DLC v1.0.

Một bản release universal duy nhất cho Codex, Claude Code và Kiro. Cài bằng prompt, quản trị bằng plan digest đã duyệt, phát hành dưới dạng immutable release.

Release status. The currently published release is v0.9.1 (2026-06-22), the last of the v0 line. v1.0 is in preparation and is not published yet — the v1.0 documents below describe it, but no v1.0 download is offered anywhere.
Trạng thái release. Bản đang phát hành là v0.9.1 (22-06-2026), bản cuối của dòng v0. v1.0 đang chuẩn bị và chưa phát hành — các tài liệu v1.0 bên dưới mô tả nó, nhưng không nơi nào cung cấp bản tải v1.0.

04 · LEGACY v0.x

Legacy v0.x — history and existing installations.

The v0 line ran a fixed seventeen-stage lifecycle and shipped two editions installed by script. It is documented here for teams still on it. It is not the v1.0 path.

Legacy v0.x — lịch sử và bản cài hiện có.

Dòng v0 chạy lifecycle cố định mười bảy stage và phát hành hai edition cài bằng script. Ghi lại ở đây cho các team còn dùng. Đây không phải đường đi của v1.0.

A v0 project does not need the v0 installer to reach v1.0. The v1 bootstrap prompt migrates v0.3-v0.9.x directly, and lists every file it would touch in the plan you approve.
Dự án v0 không cần installer v0 để lên v1.0. Prompt bootstrap của v1 migrate trực tiếp từ v0.3 đến v0.9.x, và liệt kê mọi file nó sẽ đụng tới trong plan bạn duyệt.
